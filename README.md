# AI Finder

AI Finder is a small, static directory of AI websites. Browse the list or search by name and keyword, then follow a link to the tool's own site.

## Try it locally

Open `index.html` in a browser. There is no build step or package installation.

The directory entries live in `script.js`; add or update an item there when the list changes. Suggestions are collected through the separate page in `suggestions.html`.
